# Трансформация Excel файла на VBA

Макрос разработан для автоматизации процесса подготовки файла с контактами абонентов для дальнейшей загрузки в программное обеспечение Рупро.Блиц.
Изначальный Excel файл представляет собой контактные данные абонентов. Пример шаблона представлен на рисунке ниже:

![Файл с контактами до преобразования](https://github.com/AlRovshan/File-transformation-with-VBA/blob/images/Файл%20с%20контактами%20до%20преобразования.jpg)

Необходимо преобразовать Exсel файл в файл CSV с определенным шаблоном, который  требуется для импортирования в Рубор.Блиц. Пример шаблона файла для импорта в Рупор.Блиц представлен ниже:

![Файл с контактами после преобразования](https://github.com/AlRovshan/File-transformation-with-VBA/blob/images/Файл%20с%20контактами%20после%20преобразования.jpg)

**Данный код на VBA выполняет следующие функции:**

- Получение названия списка. При запуске макроса выйдет диалоговое окно, где необходимо указать название списка или оставить поле пустым.
- Проверка последовательности записей и удаление лишних строк
- Удаление лишних пробелов
- Удаление лишних символов
- Замена цифры 8 на +7 в поле номер для sms
- Создание шаблона
	- Назначение параметров Record number и Full name
	- Назначение параметра Contact order
	- Преобразование ячеек с рабочим номером
	- Преобразование ячеек с домашним номером
	- Преобразование ячеек с мобильным номером
	- Преобразование ячеек с sms
	- Преобразование ячеек с email
- Переход на следующую строку
- Добавление названия столбцов в первую строку
- Сохранение данных в новом файле в директории предыдущего файла в формате CSV UTF-8
- Удаление всех лишних данных в книге

**Запуск файла**

Для запуска файла с расширением .bas необходимо в Excel перейти во вкладку `Разработчик` - `Visual Basic` - в открывшемся окне VB выбрать `File` - `Import file` - выбрать .bas файл.
После загрузки VBA кода на главном экране Excel перейдите во кладку `Макросы` и выполните макрос `"impt"`.

Подробная информация о шаблоне файла дли импорта данных в Рупор.Блиц указана на [официальном сайте.](https://www.speechpro.ru/product/sistemy-rechevogo-opovesheniya/rupor-blits)
